# خوشکبار و تخمه اعلا

شعار: کیفیت اعلا، خرید آسان، حساب شفاف

این بسته شامل نمونه اولیه رابط کاربری Flutter برای اپ مشتریان و سند معماری سامانه مرکزی است.

## اجرا
1. Flutter SDK را نصب کنید.
2. در پوشه پروژه اجرا کنید:
   `flutter pub get`
3. برای اجرا روی گوشی یا شبیه‌ساز:
   `flutter run`

## نکته مهم
این نسخه نمایشی است؛ ثبت‌نام پیامکی، سرور، پنل مدیریت، ذخیره سفارش، آپلود عکس/فیلم و پرداخت واقعی هنوز متصل نشده‌اند. پیش از انتشار عمومی باید backend امن و سرویس‌های مربوطه راه‌اندازی شوند.
